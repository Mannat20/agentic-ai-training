# Day 17 - Lists, Sets, Dictionaries, and Queue

**Training Program:** Agentic AI Training

**Organization:** Auribises

**Day:** 17

---

# 📖 Session Overview

The seventeenth day strengthened the understanding of Python's built-in collection types.

The session covered exception handling, multi-dimensional lists, slicing, the many operations available on lists, membership operators, mathematical operations on sets, and key-value handling in dictionaries. The assignment applied a list to implement a **Queue** that follows the First-In, First-Out (FIFO) rule.

# 📌 Key Takeaways

- Lists keep order and allow duplicates; sets keep only unique items; dictionaries store key-value pairs.
- `in` on a dictionary checks the **keys**, not the values.
- Sets make comparisons between groups very easy.
- `try` / `except` keeps a program running after an error.
- A queue removes items from the front and adds them at the back.
